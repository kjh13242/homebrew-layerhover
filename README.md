# Layerhover Homebrew tap

```bash
brew install --cask kjh13242/layerhover/layerhover
```

설치한 뒤 Layerhover를 열고, 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 Layerhover를 켜 주세요.
권한을 켜면 Layerhover가 스스로 다시 켜지고, 그 뒤부터 동작합니다.

Homebrew가 이 tap을 신뢰하지 않는다는 경고를 보여 주면, 이 cask만 신뢰하도록 설정하세요:

```bash
brew trust --cask kjh13242/layerhover/layerhover
```

업데이트와 삭제:

```bash
brew upgrade --cask layerhover
brew uninstall --cask layerhover
```
